# Edge to HISP

The Edge to HISP test suites verify a HISP’s XDR server from a sending HISP perspective. The Edge to HISP test suites are split into two sections:

-   **XDR To XDM Conversion** — Tests the HISP’s ability to convert XDR messages into SMTP messages with an XDM attachment and send the message to the address indicated in the XDR message.
-   **Delivery Notification** — Tests a sending HISP’s responsibility defined in the Implementation Guide for Delivery Notification when using XDR as the sending edge protocol.
