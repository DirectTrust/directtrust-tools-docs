# SMTP Edge

The SMTP testing tools verify an SMTP server implementation for Direct messaging. The tools include the following tests:

-   **SMTP Transport** — Tests the HISP’s ability to support SMTP transport layer compliance for Direct messaging, including TLS options, SMTP commands, and authentication.
-   **Delivery Notification** — Tests a sending HISP’s responsibility defined in the Implementation Guide for Delivery Notification when using SMTP as the sending edge protocol.
