# Certificate Hosting

The Hosting tool verifies that certificates for a given Direct address can be published and resolved. It specifically tests that your HISP can publish a certificate in accordance with the Certificate Discovery for Direct Project Implementation Guide. 

Select a Direct address from your registered list of Direct addresses and the tool will attempt to look up its associated certificates in accordance to the Certificate Discovery for Direct Project Implementation Guide.

::: tip
**Note:** You can only search for certificates for Direct addresses that you registered in the User Settings.
:::

![Certificate Hosting lookup](/images/certificate-hosting/1.png)

*Certificate Hosting lookup*

If the certificate is successfully discovered, then details of the certificate such as subject, issuer, validity period, and key usage details can be viewed by pressing the **View Certificate** button.

![Certificate discovered — View Certificate button](/images/certificate-hosting/2.png)

*Certificate discovered — View Certificate button*

![Certificate details view](/images/certificate-hosting/3.png)

*Certificate details view*

Results are automatically saved and accessible in the [Results and Reports](/results-and-reports) section.
