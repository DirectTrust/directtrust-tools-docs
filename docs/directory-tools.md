# Directory Tools

Directory Tools provide introspection into the DirectTrust Directory. Access to individual directory tools is controlled by separate permissions, so a user may have access to some but not all of these tools.

::: tip
**Tip:** Access to the Directory Tools is generally only granted to DirectTrust Directory contributors.
:::
