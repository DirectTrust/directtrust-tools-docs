# Management

The Management tools include the following functionality:

-   **[User Settings](/user-settings)** - Allows the user to update their account information at any time after initial registration.
-   **[Server Configuration](/server-configuration)** - Manages the connection profiles used by the Edge Protocol tests (SMTP, POP3, IMAP, and XDR).
-   **[Results and Reports](/results-and-reports)** - Review past results, manage test history, and generate formal reports.
