# Management

The Management tools include the following functionality:

-   **User Settings** - Allows the user to update their account information at any time after initial registration.
-   **Server Configurations** - Manages the connection profiles used by the Edge Protocol tests (SMTP, POP3, IMAP, and XDR).
-   **Results and Reports** - Review past results, manage test history, and generate formal reports.
